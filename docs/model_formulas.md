# 屈折力推定モデル式まとめ（2026-06-09版）

## 概要

楕円パラメータ (major, minor, angle) から屈折力 D [Diopter] と瞳孔径 p [mm] を同時推定する。

---

## Step 1 — 楕円パラメータの取得

AdaptDoG（`src/ellipse/adaptdog.py`）で各画像から取得：

```
major  : 長軸 [px]
minor  : 短軸 [px]
angle  : 楕円の傾き [deg]
ratio  = minor / major        （スケール不変）
area   = major × minor        （実ピクセル面積）
```

---

## Step 2 — ratio モデル（スケール不変）

Simulation データから **10次 2D 多項式** で構築（`src/analysis/ratio_model.py`）。  
係数は `data/simu_masked/ellipse_flat75/fitting_calibrated_spline/poly_model.npz` に保存。

```
ratio_real(D, p_mm) = Σ_{i+j≤10} c_{ij} × D^i × p_mm^j
```

- フィット対象: Simulation グリッド p_mm ∈ {2,3,...,9} mm × D ∈ 65点（−8D〜+8D）
- 係数数: 66 項（deg=10 の 2変数多項式）
- フィット精度: RMSE=0.01251、MaxE=0.06440、R²=0.9975

**特性：**
- D=0 付近（正視）では ratio は小さく（0.10〜0.16）、等高線がほぼ垂直 → D 感度極小
- 近視が強くなるほど ratio は増大し 1.0 に漸近
- 瞳孔径が大きいほど同じ D に対して ratio が小さい（ただし D≥−2D 付近で逆転）

## Step 3 — area モデル（実ピクセル変換済み）

`src/analysis/area_model.py`

```
area_real(D, p_mm) = α(p_mm) × k(p_mm) × area_sim(D, p_mm×5)
```

### 3-1. area モデル（多項式、α・k 込み）

```
area_real(D, p_mm) = Σ_{i+j≤10} c_{ij} × D^i × p_mm^j
```

多項式は `α(p_mm) × k(p_mm) × area_sim(D, p_mm×5)` にフィット済み（α・k 補正込み）。  
係数は `poly_model.npz` の `coef_area` に保存。  
フィット精度: RMSE=311 px²、MaxE=1976 px²、R²=0.9993

**特性：**
- p が大きいほど area は大幅に増大（7mm は 3mm の約 4〜5 倍）
- D=0 付近は area が最小（正視で pupil 面積が最小に見える）
- 近視が深くなると area は増大するが飽和傾向

### 3-2. 模型眼校正係数 k(p_mm)

模型眼の実測 area と Simulation area の比（近視安定域 D=−5,−4,−3D で平均）：

| p_mm | p_sim | k_measured |
|------|-------|------------|
| 3.0 mm | p15 | 0.4480 |
| 5.0 mm | p25 | 0.5023 |
| 7.0 mm | p35 | 0.6824 |

2次多項式フィット：

```
k(p_mm) = 0.015732 × p² − 0.098734 × p + 0.602635
```

### 3-3. 患者データ補正係数 α(p_mm)  ← 今回新設

模型眼と患者実データの乖離を補正するための p 依存スケール係数。  
2点校正：
- Abhishek（強近視、瞳孔≈3mm）→ α(3mm) = 0.40
- Dilsha（正視付近、瞳孔≈7mm）→ α(7mm) ≈ 0.568

線形補間：

```
α(p_mm) = 0.2742 + 0.0419 × p_mm
```

## Step 4 — 連立ソルバー

`experiments/refraction_from_ratio_area.py`

```
最小化: L(D, p) = [(ratio_real(D,p) − ratio_obs) / ratio_obs]²
                + [(area_real(D,p)  − area_obs)  / area_obs ]²

制約: D ∈ [−8.0, 0.0] D（近視側のみ）
      p ∈ [2.0, 9.0] mm

手法: coarse grid (65×29) で初期値探索 → scipy L-BFGS-B で連続最適化
```

**特別処理（正視付近）:**  
ratio < 0.13 の場合は D 推定不能（等高線が縦になり感度極小）。  
D = 0.00 D 固定、area 方程式のみで p を Brent 法で推定。status = "unmeasurable"。

---

## Step 5 — SCA フィット

複数画像の (D, angle) ペアからコサインフィット：

```
D(α) = P0 + P1·cos(2α) + P2·sin(2α)

SE = P0
C  = −2 × √(P1² + P2²)     （マイナス表記）
S  = SE − C/2
A  = 0.5 × atan2(−P2, −P1) mod 180  [deg]
```

## 既知課題・暫定事項

| 項目 | 状態 |
|------|------|
| α(p_mm) の校正根拠 | Abhishek（3mm仮定）と Dilsha（7mm仮定）の2点のみ。模型眼データ更新時に再校正要 |
| k(p_mm) の校正精度 | 模型眼3点のみ。新模型眼データ取得後に再導出予定 |
| 遠視側モデル | 近視側 (D≤0) のみ採用。遠視側の area モデルは校正不足 |
| ratio < 0.13 の扱い | D=0 固定は暫定。将来的に正視付近の専用処理を検討 |
| IQR フィルタの ratio 外れ値 | minor 異常大の画像を除去できない（乱視との区別が困難なため保留） |
